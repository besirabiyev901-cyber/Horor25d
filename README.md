# 👻 Horor25d

A 2.5D horror game developed with passion and suspense. 

---

## 📥 Download & Play

If you want to play the game right now, do not clone the repository directly. Instead, download the latest stable version:

👉 **[Go to Releases](../../releases)** and download the latest `Horor25d-v0.1.0.zip` archive.

### How to Play:
1. Download the archive from the **Releases** section.
2. Extract the contents to any folder on your PC.
3. Run `Horor25d.exe`. *(Make sure `Horor25d.exe` and `Horor25d.pck` stay in the same folder!)*
