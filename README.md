2.5D Space — Personal Prototype

This is a small experimental project and my first real attempt at testing 2.5D space using my own assets.

The main goal of this prototype was to explore how 2D and 3D can work together, creating a sense of depth and space without having to build a fully realistic 3D environment.

🎮 About the Project

This is not a full game, but rather a small technical and creative prototype.

I created it to experiment with:

- how my own assets look inside a 3D environment;
- combining 2D elements with 3D space;
- camera perspective and depth;
- lighting and atmosphere;
- developing a visual style that I can use in future projects.

🎨 My Creative Work

The main assets used in this prototype were created by me specifically for this experiment.

I'm currently working on developing my own visual style and learning to create not only gameplay mechanics, but also environments, objects, and visual assets for my games.

Because of that, this project is important to me not as a finished game, but as another step toward creating games where I can handle both the technical and artistic sides of development myself.

🧪 Why 2.5D?

I'm interested in the space between 2D and 3D.

Instead of completely moving toward realistic 3D, I want to combine the simplicity and stylization of 2D with the depth, perspective, lighting, and atmosphere of 3D.

This prototype is my first attempt to explore how far I can take this approach.

🔨 Technologies

- Godot Engine
- 2.5D / 2D + 3D
- Custom-made assets
- 3D environments
- Camera and lighting

🚧 Status

Prototype / Experiment

This project was created mainly for learning, experimentation, and developing my own style.

It may never become a full game, but the experience and techniques I learned here will be used in future projects.

💭 What's Next?

I want to continue experimenting with 2.5D, custom assets, cameras, lighting, and object interaction.

The long-term goal is to move from small experiments like this toward complete games where the idea, visual style, assets, and technical implementation are created by me.
